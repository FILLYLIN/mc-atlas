# Minecraft 26.3 源代码分析

面向学习与研究的静态站点：把 Minecraft（Java 版）26.3 的类作用、注册对象、实验机制与方法整理成可浏览的网页。

- 首页 `index.html` 可直接双击打开，无需服务器。
- 数据在 `assets/data/`，语言包按需加载。
- 站点由本地工作区 `mc-code-workspace` 的 `mc site` 生成，本仓库只放生成结果。
