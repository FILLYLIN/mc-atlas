26.3 运行时基线

七个版本

每个版本都有独立源码树、索引和 git 标签；运行时探针目前只覆盖未混淆的 26.x。

边界

已知限制

  • 1.21.x 的运行时数值。混淆版本要先拿 server_mappings 把服务端 jar 重映射一遍，探针才跑得起来；目前只对 26.x 直接支持。
  • 物品的堆叠 / 耐久。它们存在数据组件里，要等数据包加载（ReloadableServerResources）才绑定；只跑 Bootstrap 时 ItemStack 会抛 “Components not bound yet”。
  • 附魔、群系、伤害类型等。这些是数据包注册表（data/minecraft/**/*.json），不在 95 个内置注册表里，需要单独做 JSON 解析。
  • 角色标签基于推断。491 个类有注册表证据，其余 9,393 个只有包级 / 命名级标签。可用于定位，不替代逐行阅读。
  • 索引的已知损失。官方映射不覆盖合成成员（lambda$…、Foo$1），匿名内部类不单独成条，重载参数变化表现为“新增 + 删除”。
  • 硬度取默认状态。极少数方块会随状态/位置改变硬度，探针用默认 BlockState 取值，依赖世界的个别方块可能返回异常值（已按空值处理）。
